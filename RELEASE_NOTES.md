# Interactive Fiction v3.2.0

Talk and Give are standard player actions for accessible NPCs.

- Default responses are free refusals, with model-owned text and labels.
- Story rules can provide dialogue and accept gifts using transferToNpc.
- NPC inventories preserve ownership through movement, nested containment, timers and saves.
- The browser offers Talk and Give using the existing dispatcher and menu system.
- Authoring schema and attribute documentation cover the new NPC fields.
- World schema 2 and save format 1 are unchanged; old worlds and saves remain supported.

See docs/npc-interactions.md for model examples, rule registration and ownership semantics.
